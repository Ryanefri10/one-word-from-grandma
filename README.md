[u-0xkianno-one-word-from-grandma-f04bed16](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16):
the single word a grandma would text about AI.

`main.py` (Python 3, standard library only) writes exactly one word to
`/output/entry.txt`:

```
Whirligig
```

Nine characters, one word, no trailing newline. Grandma calls any whirring
gadget she cannot name a whirligig — warm, a little baffled, funny in one
word, tied to machines, and fresh (robit, contraption, doohickey, witchcraft
and the other obvious picks are already heavily entered).

Run it with `python3 main.py`; every run writes byte-identical output.
